System Status

Select a check above. No technical URL needs to be typed.

What the results mean

  • Backend online: Render is running and the Marketplace API can respond.
  • 0 approved adverts: The system is working, but no adverts are currently approved.
  • 1 or more approved adverts: Those adverts should appear for everyone on the public Marketplace.
  • Backend waking up: The free Render service may take a short time to start. Wait and press the check again.

Correct public API endpoint: https://marketplace-c3wq.onrender.com/api/listings/public
