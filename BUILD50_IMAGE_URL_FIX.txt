TCS Marketplace Build50 - Image URL Fix

Fix: absolute HTTPS/HTTP, data and blob URLs remain unchanged; relative API paths still use TCS_API_BASE; old https// values are repaired to https://. All marketplace/admin helpers and cache versions were updated.
