TCS Marketplace Build49 Render Startup Fix

Root cause fixed:
server.js imports initDb, health and closeDb from src/db/index.js, but the uploaded Build49 file exported only readDb, writeDb, addEvent and backupDb. Render therefore exited during startup because initDb was not a function.

Correction:
- src/db/index.js now exports initDb, health and closeDb through the Neon PostgreSQL pool.
- Legacy JSON helpers remain available for older routes.
- Render health build identifies itself as 49-vat-aware-pricing-render-fixed.
- package version is 49.0.1.

Required Render setting:
DATABASE_URL must contain the Neon pooled PostgreSQL connection string.
